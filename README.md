# Island — Dynamic Island для Windows

Живая пилюля сверху экрана. Electron + чистый JavaScript и CSS, системные функции — через встроенный мост PowerShell/C# (без нативных модулей и сборки).

## Запуск

```bash
npm install
npm start
```

`npm run dev` — то же самое, но с инструментами разработчика.

Если после `npm install` нет `node_modules/electron/dist/electron.exe` (на Node 26 распаковщик Electron иногда молча не срабатывает), распакуй архив из `%LOCALAPPDATA%\electron\Cache\…\electron-v33.2.1-win32-x64.zip` в `node_modules/electron/dist` и создай файл `node_modules/electron/path.txt` с текстом `electron.exe`.

## Что умеет

**Пилюля** — дата, время и погода. Показывает самое важное сейчас: трек с обложкой и эквалайзером, загрузку из браузера, таймер, работающего агента, «нужен ответ», «готово». Вторая активность — маленький кружок справа. Наведение на играющую музыку — мини-плеер.

**Клик** — остров раскрывается во вкладки (порядок и состав настраиваются, `Ctrl+1…8` — переключение):

| Вкладка | Что внутри |
|---|---|
| Главная | Большой плеер с мягким отражением обложки, синхронный текст песни (lrclib), громкость именно этого плеера; быстрые действия; погода; полка файлов; агенты; уведомления. Виджеты включаются/переставляются, сетка подстраивается |
| Буфер | Всё скопированное: текст, ссылки, картинки, файлы, цвета. Откуда и сколько минут назад. Закрепить, удалить, поиск, фильтры. Клик — вставка туда, где печатал |
| ИИ | Gemini, DeepSeek, ChatGPT, локальная Ollama. Файлы (перетащить, прикрепить, Ctrl+V картинки), голос, история, отдельное окно |
| Текст | Раскладка (ghbdtn → привет), транслит, регистры, camel/snake/kebab, пробелы, сортировка, дубли, типограф, URL/Base64, JSON, перевод, «исправить ИИ», голос в текст, «взять выделенное» из окна |
| Заметки | Как в iPhone: список + редактор, закрепление, поиск, напоминания и таймеры внутри заметки обычной фразой |
| Погода | Анимированная сцена, почасовой прогноз, неделя, плитки: компас ветра, влажность, давление, солнце, осадки, УФ. Цифры «оживают» при открытии. Предупреждение перед дождём |
| Центр | Wi-Fi (список сетей, ввод пароля, подключение), Bluetooth, VPN, тёмная тема Windows, «не беспокоить», звук, «не засыпать», громкость, яркость; блокировка, сон, перезагрузка, выключение. Плитки меняются кнопкой «Изменить» |

**Настройки** — отдельное окно (вкладка «Настройки», правый клик по острову или трей): разделы слева, поиск по всем настройкам, справа живое превью того, что меняет строка, и отметка «Применено».

**Правый клик** по острову — меню: вкладки, командная строка, скриншоты, тема, материал, характер, «Не беспокоить», «Спрятать на 30 минут».

**Alt+Space** — одна строка на всё: программы, файлы (через индекс Windows), `15% от 2000`, `2000 + 15%`, `10 миль в км`, `100$`, `50 евро в рублях` (курс ЦБ), `таймер 5 мин`, `напомни через 20 минут позвонить`, `напомни завтра в 9 …`, команды (`скрин`, `пипетка`, `qr`, `тема`…), **Tab** — спросить ИИ прямо в строке.

**Перетащи файл на остров** — две зоны: «На полку» (потом вытянешь обратно) и «Спросить ИИ».

**Скриншот** (`Alt+Shift+S` или быстрые действия): область, перо, маркер, рамка, стрелка, текст, размытие; распознать или перевести текст со скрина; QR; пипетка с лупой. Результат сразу в буфере — остров на 2 секунды скажет «Изображение сохранено в буфере».

**Агенты в терминале.** Настройки → «Агенты» → «Подключить» добавляет хуки в `~/.claude/settings.json` (с резервной копией). Остров показывает «Claude трудится», зовёт, когда нужно разрешение или ответ, и отмечает готовую задачу. Разрешения (Разрешить / Запретить) и вопросы можно отвечать прямо с острова. Для Codex добавляется `notify` в `~/.codex/config.toml` — уведомление о завершении хода.

**Характер.** Глаза следят за курсором, моргают, танцуют под музыку, задумываются, пока думает ИИ или агент, радуются готовому, вздрагивают от уведомлений и засыпают, когда тебя долго нет. Можно выбрать «человечков» под пилюлей.

**Вид.** Жидкие переливы, стекло, бегущий градиент или сплошной; любые три цвета и палитры; ободок с анимированным градиентом; свечение за курсором; остров тянется к мыши. Края как вода: тянутся к курсору, расходятся рябью, когда входишь в остров. Под музыку низ светится цветом обложки, а на удары баса край вздрагивает и расходятся светящиеся круги. Светлая/тёмная тема — `Alt+Shift+D`.

**Полноэкранный режим** — остров прячется; подведи мышь к центру верхнего края, и он появится.

## Ключи и данные

Всё хранится в `%APPDATA%\Island\` (настройки, буфер, заметки, чаты). Ключи ИИ — там же, в `settings.json`.

- Gemini — бесплатный ключ: https://aistudio.google.com/apikey (вход Google-аккаунтом, ключ за минуту).
- DeepSeek — https://platform.deepseek.com/api_keys
- ChatGPT — https://platform.openai.com/api-keys
- Ollama — без ключа, если установлена локально.
- Telegram — `api_id`/`api_hash` с https://my.telegram.org/apps, затем «Войти в Telegram»: код и пароль 2FA вводятся на острове, сохраняется только сессия.

Буфер не сохраняет то, что менеджеры паролей помечают как секрет.

## Ограничения Windows

- Стекло не размывает рабочий стол под островом: у окна произвольной формы Windows не даёт настоящий acrylic, поэтому стекло нарисовано (блики и полупрозрачность).
- Bluetooth: включение/выключение и список устройств работают, а подключение конкретных наушников Windows разрешает только из своих параметров — остров открывает их.
- VPN: включаются профили VPN Windows (`rasdial`). Сторонние клиенты (WireGuard, Outline и т.п.) управляются своими программами.
- Уведомления Windows читаются из базы уведомлений системы; если приложение их отключило, остров их тоже не увидит — для этого есть Telegram.
- Ответы на вопросы `AskUserQuestion` Claude Code с острова — экспериментальные; если версия Claude Code не примет ответ, вопрос останется в терминале.
- Вход в Gemini через Google-аккаунт вместо ключа требует собственного OAuth-клиента в Google Cloud, поэтому используется ключ из AI Studio.
